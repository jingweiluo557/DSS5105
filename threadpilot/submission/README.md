# Final submission sources (Group19.zip)

The PDFs and Word files in Group19.zip are rendered from the HTML here, so a change to any document is one edit and one command.

| Output | Source | Build |
|---|---|---|
| Readme.pdf, Teams.pdf, Documentation.pdf, Strategic_Recommendations.pdf | the HTML file of the same name | `node build_pdf.cjs <name>.html <out.pdf> "<footer title>"` |
| Evaluation.pdf | `Evaluation.html` + the tables generated from the repo | `python3 make_tables.py && python3 inject.py Evaluation.html _Evaluation.built.html && node build_pdf.cjs _Evaluation.built.html <out.pdf> "Evaluation report"` |
| *.docx | the same HTML | `python3 docx/to_docx.py <name>.html <out.docx>` (tables for the CSS-only layout, then pandoc with `docx/reference.docx`), then `python3 docx/fix_docx.py <out.docx>` (A4, full-width tables, smaller code text). Use `_Evaluation.built.html` for Evaluation.docx |
| Slide.pptx | the Sprint 3 deck (`../demo/slides_sprint3/`), as an editable PowerPoint with each speaker's lines in the notes | built with pptxgenjs from the same slide text; the video's slides are rendered by `node ../demo/render_slides.cjs --slides ../demo/slides_sprint3` |
| Video.mp4 | the full product demo, on the offline replay: one working day, no slides, 4:56, captions burned in (the AI agent's spoken replies are subtitled word for word), the phone's spoken replies as sound. Three recordings (desk 07:00, phone and voice 09:40, desk for the rest of the day) from `../demo/demo_timeline_demo_{a,b,c}.json`, generated by `../demo/make_timeline_demo.py` | see "Full product demo" in `../demo/README.md`: start the replay server, run `record_demo.cjs` once per part, then `python3 ../demo/assemble_demo.py <parts> <out> --badge "…"` |

`make_tables.py` reads `docs/TOOL_SPECIFICATION.md`, `evaluation/EVALUATION.md`, `heldout_questions.json` and `bait_questions.json`, so the appendix tables are never retyped. The generated `fragments/` and `_*.built.html` files are build products and are not committed.
