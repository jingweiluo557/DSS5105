Three failures that changed the design

“What is the status of the order that was late yesterday?”

Before

Answered about ORD-002, the order that happened to be open on screen.

Now

Lists the 8 overdue orders and asks which one.

“Will ORD-093 be late?”

Before

“Six days after the due date”: a field that meant working days from today.

Now

“Already 3 days overdue; best case 7 Apr, 8 working days after the due date.”

“How many pieces has assembly lost since 25 March?”

Before

Counted 25 March only: 410 short. Related questions looped on “which date?”.

Now

2,553 made in 6 working days, 2,108 short of the same-weekday norm.

Each traced to a server rule, not the model. Each question is now a regression test.

1:56–2:18 · [Presenter 3]. “Three failures that changed the design. A described order was silently replaced by whatever was open on screen; now the description decides, and it asks. A field name made the model say ‘six days late’ for an order three days overdue; now overdue days and working days after the due date are separate fields. And a period like ‘since 25 March’ was read as one day, or sent it into a ‘which date?’ loop; now periods are a tool, so it answers 2,553 pieces, 2,108 short. None of these was the model’s fault, and each is now a test.”
